## 🛠️ Guía de Comandos Git para Envío de Entregables (PRs)

A continuación se detallan los comandos recomendados para preparar la rama, guardar los cambios localmente, subir las ramas y crear los Pull Requests de forma ejecutiva:

### 1. Crear y cambiar a la rama de actividad
Siempre trabajá sobre la rama asignada en el ticket:
```bash
git checkout -b feature/nombre-de-rama-especifica
```

### 2. Agregar los cambios al área de preparación (staging)
Podés agregar todos los archivos o especificar la ruta exacta (se recomienda usar comillas en Windows cuando hay paréntesis en la ruta del archivo):
```bash
# Agregar todo
git add .

# Agregar archivos específicos (evita errores con paréntesis en cmd/powershell)
git add "src/app/(app)/proveedores/FormularioProveedores.tsx"
```

### 3. Confirmar los cambios
Escribí mensajes de commit semánticos y limpios:
```bash
git commit -m "feat: implement supplier list view and dynamic order points calculations"
```

### 4. Subir la rama a GitHub
Publicá los commits en el repositorio remoto:
```bash
git push origin feature/nombre-de-rama-especifica
```

### 5. Crear la Pull Request (PR) en GitHub
Utilizá el CLI de GitHub (`gh`) para generar la PR de forma automática:
```bash
gh pr create --title "feat: título de la actividad" --body "Descripción técnica del cambio y verificación de pruebas."
```
